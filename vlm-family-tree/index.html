How to read it

Vision encoder
Turns pixels into visual tokens.

VLM
Connects visual tokens to a generative language model.

Language backbone
Provides the text/reasoning decoder.

A line means “uses / is built on”, not that one VLM was trained from another. Connector details are model-specific and intentionally not collapsed into this two-parent view.

Last curated: November 2025. “SOTA” is task- and benchmark-dependent, so the map avoids a single universal claim. Source links point to official repositories, model cards, or technical reports; unknown proprietary compositions are deliberately excluded.
